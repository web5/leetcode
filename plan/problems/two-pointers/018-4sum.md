# 18. 四数之和（中等）

> https://leetcode.cn/problems/4sum/
> 标签：数组、双指针、排序
> 作答文件：`solutions/018-4sum.js`（按计划手动编写）

## 题目描述

给你一个由 `n` 个整数组成的数组 `nums`，和一个目标值 `target`。请你找出并返回满足下述全部条件且 **不重复** 的四元组 `[nums[a], nums[b], nums[c], nums[d]]`（若两个四元组元素一一对应，则认为两个四元组重复）：

- `0 <= a, b, c, d < n`
- `a`、`b`、`c` 和 `d` **互不相同**
- `nums[a] + nums[b] + nums[c] + nums[d] == target`

你可以按 **任意顺序** 返回答案。

## 示例

**示例 1：**
- 输入：`nums = [1,0,-1,0,-2,2], target = 0`
- 输出：`[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]`

**示例 2：**
- 输入：`nums = [2,2,2,2,2], target = 8`
- 输出：`[[2,2,2,2]]`

## 提示

- `1 <= nums.length <= 200`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`

## 与 15 题的关系

在三数之和外面再套一层循环。**真正的坑是溢出**：`nums[i]` 到 `1e9`，四个相加会超过 JS 的 `Number.MAX_SAFE_INTEGER`？不会（1e9 × 4 = 4e9 仍在安全范围），但换成 `int` 的语言就会溢出——面试里要主动说出来。其它坑是「两层都要去重」。
