# 209. 长度最小的子数组（中等）

> https://leetcode.cn/problems/minimum-size-subarray-sum/
> 标签：数组、二分查找、前缀和、滑动窗口
> 作答文件：`solutions/209-minimum-size-subarray-sum.js`（按计划手动编写）

## 题目描述

给定一个含有 `n` 个正整数的数组和一个正整数 `target`。

找出该数组中满足其总和大于等于 `target` 的长度最小的 **子数组** `[nums_l, nums_{l+1}, ..., nums_{r-1}, nums_r]`，并返回其长度。如果不存在符合条件的子数组，返回 `0`。

## 示例

**示例 1：**
- 输入：`target = 7, nums = [2,3,1,2,4,3]`
- 输出：`2`
- 解释：子数组 `[4,3]` 是该条件下的长度最小的子数组。

**示例 2：**
- 输入：`target = 4, nums = [1,4,4]`
- 输出：`1`

**示例 3：**
- 输入：`target = 11, nums = [1,1,1,1,1,1,1,1]`
- 输出：`0`

## 提示

- `1 <= target <= 10^9`
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^4`

## 进阶

如果你已经实现 `O(n)` 时间复杂度的解法，请尝试设计一个 `O(n log n)` 时间复杂度的解法。

## 为什么它比 76 简单

同样是可变长窗口，但「满足条件」在这里是**求和单调递增**（全正整数），所以窗口一满足就可以立刻收缩，不需要 `need/matched` 那种计数。做完请对比 76 与本题的「窗口条件怎样 O(1) 判断」。
