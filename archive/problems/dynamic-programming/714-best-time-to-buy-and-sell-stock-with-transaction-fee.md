# 714. 买卖股票的最佳时机含手续费（中等）

> https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-transaction-fee/
> 标签：贪心、数组、动态规划
> 答案：[solutions/714-best-time-to-buy-and-sell-stock-with-transaction-fee.js](../../solutions/714-best-time-to-buy-and-sell-stock-with-transaction-fee.js)
> 族谱：[dp/README.md §10.5 股票族一刷脚本与迁移表](../../dp/README.md)（122 的「交易成本维」代表）

## 题目描述

给定一个整数数组 `prices`，其中 `prices[i]` 表示第 `i` 天的股票价格；整数 `fee` 代表了交易股票的手续费用。

你可以无限次地完成交易，但是你每笔交易都需要付手续费。如果你已经购买了一个股票，在卖出它之前你就不能再继续购买股票了。

返回获得利润的最大值。

**注意：** 这里的一笔交易指买入持有并卖出股票的整个过程，每笔交易你只需要为支付一次手续费。

## 示例

**示例 1：**
- 输入：`prices = [1, 3, 2, 8, 4, 9], fee = 2`
- 输出：`8`
- 解释：能够达到的最大利润：
  - 在此处买入 `prices[0] = 1`
  - 在此处卖出 `prices[3] = 8`
  - 在此处买入 `prices[4] = 4`
  - 在此处卖出 `prices[5] = 9`
  - 总利润：`((8 - 1) - 2) + ((9 - 4) - 2) = 8`

**示例 2：**
- 输入：`prices = [1, 3, 7, 5, 10, 3], fee = 3`
- 输出：`6`

## 提示

- `1 <= prices.length <= 5 * 10^4`
- `1 <= prices[i] < 5 * 10^4`
- `0 <= fee < 5 * 10^4`

## 为什么它属于「交易成本维」

族谱里的两条正交支线（见 `dp/README.md §10.5.6`）：

```
笔数维（限制交易次数）：121（1 笔） → 188（k 笔） → 123（k = 2 特化）
交易成本维（k 无限制）：122（无限笔） → 714（+ 手续费） / 309（+ 冷冻期）
```

714 = **122 再加一处**：卖出时扣一次 `fee`。

```
122：hold = max(hold, cash - p)          cash = max(cash, hold + p)
714：hold = max(hold, cash - p)          cash = max(cash, hold + p - fee)
                                            ↑ 只多这一个 -fee
```

## 两个必须想清楚的点

**① 手续费只能扣一次，且推荐在「卖出」时扣**
买卖两头都扣 = 一笔交易被收两次钱，答案会偏小。在卖出扣的写法最直观：一次完整交易 = 一次卖出 = 一次手续费。

**② 122 的差分贪心直接搬过来是错的**

122 的做法是「把每天的正差分段全加起来」（`Σ max(0, p[i] - p[i-1])`），因为无成本时每段上升都能独立吃掉。
加了手续费后不能这么算——用示例 1 试算：上升段分别是 `1→3`（+2）、`2→8`（+6）、`4→9`（+5），逐段各扣一次 fee 得 `0 + 4 + 3 = 7`，而正确答案是 `8`（最优是 `1→8` 与 `4→9`，即**放弃 1→3 那一小段，改从更低的 1 建仓**）。

含手续费的贪心要改成「维护**含手续费的最低买入成本**」：

```
if (p < minPrice) minPrice = p                 // 更低点买入
else if (p > minPrice + fee) {                 // 有得赚才卖
  profit += p - minPrice - fee
  minPrice = p - fee                           // 关键一行：抬高成本，避免后续上涨被二次收费
}
```

**③ 面试追问**：若再加「最多 k 笔」怎么办？→ 回到 188 的 `buy[j]/sell[j]`，把 `sell[j] = max(sell[j], buy[j] + p)` 改成 `+ p - fee` 即可，两个维度可自由叠加。
