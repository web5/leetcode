## 0. 这份文件解决什么问题

`templates/` 和 `problems/` 都是**「算法 → 题目」**的方向：先知道用哪个模板，再往下写。
那份方向长不出逻辑图，只长得出查表——打开 `problems/dp/` 的那一刻，你就已经知道答案了。

**这份文件的方向是反的：题干特征 → 候选算法。**
入口必须是你在白板上第一眼看到的东西（"连续子数组"、"下一个更大"、"有多少种方案"），而不是章节名。

维护规则（比内容重要）：

1. **只允许从「特征」这一列开始想**，禁止从"算法"列反推（§4 那张表只给复习反查用）。
2. 每做完一道题，问自己一句：**题干里哪个词让我想到它？** 想不出来 → 这题等于没学，只是抄了一遍。
3. **判据必须能给出「否掉理由」**。写"用单调栈"是没用的；写"因为暴力要重复扫描右侧，栈把'还在等更大值的元素'挂起"才有用。
4. 遇到新的错误方向，**补进"否掉的那条路"** —— 这一栏是这份文件唯一真正有价值的东西。

## 2. 各族的决策链

每节格式固定：**触发特征 → 候选 → 判据 → 否掉的那条路**。

### 2.1 连续子数组 / 子串

**触发特征**：题干出现「连续」「子数组」「子串」「窗口」「最长/最短/恰好为 k」。

**候选**：滑动窗口 / 前缀和 + 哈希 / DP / 单调队列。

| 判据 | 选谁 | 母题 |
| --- | --- | --- |
| 窗口能否**单向扩张**（加元素后性质单调） | 滑动窗口，变长 | [3](problems/sliding-window/003-longest-substring-without-repeating-characters.md) |
| 窗口长度固定，要窗口内的极值 | 单调队列 | [239](problems/sliding-window/239-sliding-window-maximum.md) |
| 问「和/异或 = k 的**个数**」 | 前缀和 + 哈希计数 | [560](problems/prefix-sum/560-subarray-sum-equals-k.md) |
| 有后效性（当前最值不唯一、依赖多个历史状态） | DP（可能要双状态） | 152 乘积最大子数组 |

**否掉的那条路（关键边）**：
- **数组含负数 → 滑动窗口立刻出局**，只能用前缀和。因为"和"不再随右端点单调，收缩左端点可能让和变大也可能变小，窗口的单调性假设崩了。560 就是靠这条边区分开的。
- **3 为什么能滑窗**：`[l, r]` 有重复字符时，`[l, r+1]` 必然也有重复 —— 右端扩张不会让非法变合法，所以左端可以放心右移。这是滑窗合法性的**唯一**理论依据，套任何题都要先验这一条。
- **定长窗口求最值不要用堆**：堆删不掉已滑出的元素（或需要懒删除），单调队列 O(n) 更干净。

### 2.2 「下一个更大 / 更小」

**触发特征**：题干出现「下一个更大」「下一个更小」「左边/右边第一个比它大」「环形」「柱状图/接雨水」。

**候选**：单调栈（单侧 / 环形 / 贡献法）。

| 判据 | 选谁 | 母题 |
| --- | --- | --- |
| 找右侧第一个更大 | 递减栈，从左到右 | [739](problems/stack/739-daily-temperatures.md) |
| 环形数组 | 数组长度 ×2 或下标取模跑两轮 | 503 |
| 求「以 i 为最低点的最大面积/蓄水量」 | 贡献法：每个元素算左右边界 | 84、42 |
| 相邻重复元素要去重 | 单调栈 + 贪心（栈内保证唯一） | 316、402 |

**否掉的那条路**：暴力 O(n²) 之所以慢，是因为"每个元素都要向右侧扫一遍找更大的"。单调栈的本质是**把"还没有等到更大值的元素"挂起**，一遇到更大的就批量结算 —— 每个元素进出栈各一次，所以 O(n)。这句话就是这道题的逻辑图，比"单调栈模板"有用得多。

### 2.3 有序 / 可单调判定

**触发特征**：「有序」「旋转排序数组」「找某个值/边界」「最小化最大值」「最大化最小值」「最少需要多少天/船/天」。

**候选**：二分查找（三种）/ 二分答案 / 双指针对撞。

| 判据 | 选谁 | 母题 |
| --- | --- | --- |
| 数组有序，查一个值或边界 | 二分：统一写成 **lower_bound 语义** | [34](problems/binary-search/034-find-first-and-last-position-of-element-in-sorted-array.md) |
| 数组被旋转过 | 二分 + 每轮先判哪一侧有序 | 33、153 |
| 数组没序但能"爬坡" / 找局部极值 | 二分相邻比较 | 162 |
| 问「最小的最大值」且 `check(x)` 单调 | **二分答案** + 贪心 check | 875、1011、410 |
| 有序 + 从两端能丢一侧 | 双指针对撞 | [11](problems/two-pointers/011-container-with-most-water.md) |

**否掉的那条路**：
- **为什么区间语义要统一成 lower_bound**：`while (l <= r)` + `mid = (l+r)>>1` 的写法在"查找边界"时极易死循环或漏解。统一 lower_bound 后区间语义唯一（"第一个 ≥ target 的位置"），不用每次重新推 —— 这不是记忆，是**消灭了一种歧义**。
- **11 为什么能双指针**：宽度必然缩小，所以面积只取决于高度；移动长板高度不可能增加（仍受短板限制），是**无效动作**，所以只能移动短板。推出"移动长板无效"这一步之后，双指针是必然结论，不是技巧。

### 2.4 链表

**触发特征**：「链表」「倒数第 N 个」「是否有环」「K 个一组」。

| 判据 | 选谁 | 母题 |
| --- | --- | --- |
| 需要定位/找中点/判环/找倒数第 N | 快慢指针 | [141](problems/linked-list/141-linked-list-cycle.md)、19 |
| 需要构造新链、头部会被改 | 哑节点 dummy | 21、2 |
| 反转 | 三指针迭代 / 递归 | [206](problems/linked-list/206-reverse-linked-list.md) |
| 归并 / 找中点后合并 | 快慢找中点 + 反转 + 归并 | 148、143 |

**否掉的那条路**：链表题的"难"几乎都来自**指针改写顺序**，而不是算法。写之前先画三个指针（prev / cur / next），明确"哪一行之后哪条链断开"，就不会写错。这不是背模板，是缺一张图。

### 2.5 二叉树 / BST

**触发特征**：「二叉树」「BST」「路径」「深度 / 直径」「最近公共祖先」「第 k 小」。

| 判据 | 选谁 | 母题 |
| --- | --- | --- |
| 答案由子树汇总而来（高度、直径、最大路径和） | **后序 / 自底向上返回** | [104](problems/binary-tree/104-maximum-depth-of-binary-tree.md)、543、124 |
| 需要从根往下携带约束 | **自顶向下传参** | 98（传上下界） |
| 需要层信息 / 每层分组 | BFS 层序 | 102、199 |
| BST + 求第 k 小 / 验证有序 | 中序（升序） | [94](problems/binary-tree/094-binary-tree-inorder-traversal.md)、98、230 |
| 两棵树同步走 | 双指针递归 | 101 |

**否掉的那条路（本仓最强的一条边）**：**98 为什么不能只比较父子节点**？
反例 `[5, 1, 4, null, null, 3, 6]`：4 是 5 的右孩子（合法），但 3 在 5 的右子树里却小于 5 —— 局部父子关系全对，全局约束已破。
所以必须传上下界，把"整棵子树的取值范围"带下去。记反例比记"用上下界"牢固得多。

### 2.6 网格 / 图 / 依赖关系

**触发特征**：「网格」「岛屿 / 连通块」「最短」「扩散 / 传染」「先修课 / 依赖」「可以互相到达」。

| 判据 | 选谁 | 母题 |
| --- | --- | --- |
| 数连通块 / 判断是否相连，不问距离 | DFS 或并查集 | [200](problems/graph/200-number-of-islands.md)、[547](problems/graph/547-number-of-provinces.md) |
| 求**无权**最短步数、需要逐层扩散 | BFS | 994、542、127 |
| 有**多个**起点同时扩散 | 多源 BFS（初始全部入队） | [994](problems/graph/994-rotting-oranges.md) |
| 边权非负 + 单源最短路 | Dijkstra + 手写堆 | [743](problems/graph/743-network-delay-time.md) |
| 有中转次数限制 | Bellman-Ford / 分层最短路 | 787 |
| 有依赖顺序、要判环 | 拓扑排序（BFS 入度法） | 207、210 |
| 边会**动态增加** + 判连通 | 并查集 | 684、721、947 |
| 判能否二染色 | 染色 BFS/DFS | 886 |

**否掉的那条路**：
- **994 为什么不能 DFS**：问的是"最短时间"，DFS 无法保证先到达就先结算，节点会被多次更新。BFS 逐层推进天然给出首次到达 = 最短距离。**"问不问距离"就是 DFS 与 BFS 的分界线**。
- **200 为什么 DFS 就够**：只问连通块个数，不问距离，DFS 淹没整块即可，不需要距离有序。
- **200 的 DFS 有爆栈风险**（递归深度可达 m·n = 9 万层），要说出并查集 / 显式栈这两个替代方案 —— 这是取舍，不是背诵。
- **大网格 + 动态加边一律并查集**：DFS 每次都要重跑一遍，并查集是增量的。

### 2.7 DP：先判是不是 DP，再判几维

**触发特征**（这才是 DP 的入口，比"状态定义"重要得多）：

| 题目问法 | DP 类型 |
| --- | --- |
| 最大 / 最小 / 最多 / 最少 | 最优值 DP |
| 有多少种方案 / 走法 / 组合数 | 计数 DP |
| 能不能 / 是否可以 / 能否凑出 | 可行性 DP |
| 有"选或不选" + 容量或次数上限 | 背包 |
| 两个字符串互相比较 | 二维序列 DP（1143、72） |
| 区间两端取 / 子串回文 | 区间 DP（312、516、5） |
| 树上做 DP | 后序 + 返回多状态（337、124） |
| 状态是"选出的集合" | 状压 DP |

判完类型后，走 [121 文档 §103 的通用五问](problems/dynamic-programming/121-best-time-to-buy-and-sell-stock.md)：状态 / 转移 / 初始化 / 遍历顺序 / 答案。

**加维的判据**（什么时候要多一维）：
- 有**次数上限** → 加 k 维（[188](problems/dynamic-programming/188-best-time-to-buy-and-sell-stock-iv.md)）；无限次 → 完全背包；只一次 → 0-1 背包
- 有**后效性** → 拆状态：
  - 有冷静期 → 状态机加"冷冻"态（[309](problems/dynamic-programming/309-best-time-to-buy-and-sell-stock-with-cooldown.md)）
  - 有手续费 → 转移时扣一次（[714](problems/dynamic-programming/714-best-time-to-buy-and-sell-stock-with-transaction-fee.md)）
  - 乘积最大（负负得正）→ 同时存 max 和 min（152）

**否掉的那条路（整份文档里最值钱的一条边）**：

[121](problems/dynamic-programming/121-best-time-to-buy-and-sell-stock.md) 与 [122](problems/dynamic-programming/122-best-time-to-buy-and-sell-stock-ii.md) 的状态定义**完全相同**，只差转移里的一个买入项：

```
121（只交易一次）：  dp[i][1] = max(dp[i-1][1], -p[i])
122（无限次交易）：  dp[i][1] = max(dp[i-1][1], dp[i-1][0] - p[i])
```

差别只在"买入前允不允许已有收益"。**"一次"与"无限次"的全部差异就是这一个词**。
能说出这句，股票族五道题（121/122/188/714/309）就只剩一个母题；说不出，就是五道题背五遍。

### 2.8 求「所有」具体方案

**触发特征**：「所有可能的」「列出全部」「返回所有组合 / 排列 / 切割方案」。

候选只有一个：回溯。真正的判据在**同一模板内的分叉**：

| 判据 | 做法 | 母题 |
| --- | --- | --- |
| 组合（顺序无关，不回头选） | 传 `start` 下标 | [46](problems/backtracking/046-permutations.md)、78、39 |
| 排列（顺序有关，元素不能重复用） | `used` 数组 | 46、47 |
| 原数组有重复元素，要去重 | 先排序 + **同层跳过相同元素** | 47、90、40 |
| 结果长度有要求，或需要提前判断可行性 | 剪枝（如括号合法性、剩余长度） | 22、93 |
| 网格上走路径 | 原地标记 + 回溯还原 | 79、51 |

**否掉的那条路**：**"同层去重"和"同枝去重"是两个不同的东西**，混淆是 47 / 90 出错的第一原因。同层去重是"这一轮选过的值不再选"（避免结果重复），同枝去重是"这个元素用过了"（`used`）。分不清就必然写错。

### 2.9 设计题 / 流式 / 反复查询

**触发特征**：「设计一个数据结构」「O(1) 或 O(log n) 完成某操作」「数据流」「中位数」。

| 判据 | 选谁 | 母题 |
| --- | --- | --- |
| 要按「最近使用」淘汰 | 哈希 + **双向**链表 | 146 |
| 要按频次淘汰（LFU） | 频次维度 + 双向链表 | 460 |
| 动态中位数 / 第 k 大流 | 大顶堆 + 小顶堆 | 295、1046 |
| 前 K 个高频 | 桶排序 / 堆 | 347 |
| 区间重叠计数（会议室） | 扫描线 / 小顶堆 | 253 |
| 滑动窗口求最值 | 单调队列 | [239](problems/sliding-window/239-sliding-window-maximum.md) |
| 只保留最近 N 条 | 队列 | [933](problems/queue/933-number-of-recent-calls.md) |
| 前缀匹配 | Trie | 208 |

**否掉的那条路**：**146 为什么必须"哈希 + 双向链表"两个都要**：
哈希能 O(1) 找到节点，但**无序**，无法知道谁最久没被用；链表能保序，但**查找是 O(n)**。两个结构各自补对方的短板 —— 这一步推理才是这道题的全部，代码只是它的翻译。另外必须是**双向**链表：单向链表删不掉"当前节点"（找不到前驱）。

### 2.10 位运算

**触发特征**：「只出现一次」「不使用额外空间」「二进制 / 逐位」。

| 判据 | 选谁 | 母题 |
| --- | --- | --- |
| 其他元素都出现**偶数**次 | 全体异或 | [136](problems/bit-manipulation/136-single-number.md) |
| 其他元素都出现**奇数**次（如 3 次） | 逐位计数，每位对 3 取模 | 137 |
| **两个**元素只出现一次 | 全体异或 → 按最低置位分组 | 260 |
| 求 1 的个数 / 判 2 的幂 | `n & (n - 1)` | 191、231 |
| 1~n 缺一个数 | 异或 / 数学求和 | 268 |

**否掉的那条路**：**异或消去的前提是"出现偶数次"**。137（出现 3 次）不能用异或，因为 3 是奇数，异或完不会消掉 —— 所以要换"逐位取模"。这个前提一旦松动，方法就随之更换。

### 2.11 卡点：该用贪心还是 DP

这是全仓最容易误判的一处，单独拉出来。

**判据**：做完局部最优选择后**会不会后悔**（局部最优能否推出全局最优）。
- 不会后悔 → 贪心
- 会后悔 → DP

**否掉的那条路（用反例，不用记忆）**：

- **贪心成立**：[55 跳跃游戏](problems/greedy/055-jump-game.md) —— 只关心"最远能到哪"，维护右边界即可，不需要回头。45 同理（每层跳到最远）。
- **贪心不成立**：**322 零钱兑换**，面额 `[1, 3, 4]`，凑 6。
  贪心每次拿最大面额 → `4 + 1 + 1` = 3 枚；最优是 `3 + 3` = 2 枚。**拿走 4 的那一刻就后悔了** → 必须用 DP（完全背包求最少）。
- **区间调度类**：贪心**成立**，但前提是**按右端点排序**（435、452）。按左端点排序会错 —— 差别在"给后面的区间留出最大空间"。

> 一句话记法：贪心的证明方式是**交换论证 / 反例检验**，不是"感觉对"。说不出为什么不会后悔，就应该往 DP 想。

## 3. 每道新题的补录模板

做完一道题，只补这三行到对应的 §2.x 小节里（补进表格或"否掉的那条路"）：

```
题干特征：____（是哪个词/哪句话让你想到这个方向？不要写章节名）
候选方向：____、____（至少写出两个，然后逐个给否掉理由）
否掉理由：____（复杂度不够？反例？还是性质不满足？）
```

第 2 行写不出两个候选 → 这题是蒙对的；第 3 行写不出理由 → 这题记的是答案不是方法。

| 算法 | 它对应的题干特征 |
| --- | --- |
| 滑动窗口 | 连续、最长/最短、窗口单调 |
| 前缀和 + 哈希 | 子数组和为 k 的**个数**、有负数 |
| 单调栈 | 下一个更大/更小、左右最近、贡献法 |
| 单调队列 | 定长窗口最值 |
| 双指针对撞 | 有序 + 能丢一侧 |
| 快慢指针 | 链表找中点 / 判环 / 倒数第 N |
| 二分答案 | 最小化最大值 + check 单调 |
| DFS | 连通块、不求距离 |
| BFS | 无权最短路、逐层扩散 |
| 多源 BFS | 多起点同时扩散 |
| 拓扑排序 | 依赖顺序、判环 |
| 并查集 | 动态加边、连通性增量维护 |
| Dijkstra | 非负权单源最短路 |
| 回溯 | 求**所有**具体方案 |
| 贪心 | 局部最优不后悔 + 反例检验 |
| DP | 最值/计数/可行性 + 有后效性 |
| 双堆 | 动态中位数 |
| 哈希 + 双向链表 | 按最近使用淘汰 |
| 位运算 | 只出现一次、不用额外空间、偶数次消去 |

## 5. 和另外两个文件的分工

| 文件 | 回答的问题 | 什么时候看 |
| --- | --- | --- |
| `archive/decision-tree.md`（本文） | **这题该想哪个方向？** | 拿到**新题**、题干看不懂考点时 |
| `templates/` | 确定了方向之后，骨架怎么写？ | 方向定了，开始写代码时 |
| `problems/` + `solutions/` | 这道题的具体答案和踩坑 | 写完对照、复盘时 |

顺序是 **decision-tree → templates → problems**。
