# 滑动窗口（sliding window）

本目录的分类说明与解题模板，配合各题 `.md` 一起看。

## 一、它解决什么问题

维护一个**连续区间** `[left, right]`，右指针负责扩张、左指针负责收缩，用来求「最长 / 最短 / 恰好满足条件」的**连续**子数组或子串。

## 二、能用它的前提（识别信号）

1. 求的是**连续**子数组 / 子串，不是子序列；
2. **单调性**：窗口扩张时目标指标只增不减（反之亦然），所以左指针**只前进、不回退**；
3. 数组元素通常非负——含负数时窗口和不再单调。

> 反例：`nums` 含负数且求「和为 k 的连续子数组」→ 前缀和 + 哈希（见 [560](../prefix-sum/560-subarray-sum-equals-k.md)）。

判断标准只有一条：**窗口收缩后，还需要把左指针往回挪吗？** 需要，就用不了这个技巧。

## 三、两类变体：答案更新时机不同

| 类型 | 收缩条件 | 更新答案时机 |
| --- | --- | --- |
| 求最长 | 窗口**不合法**时收缩 | 每轮扩张**之后** |
| 求最短 | 窗口**合法**时收缩 | 收缩循环**内部**、收缩**之前** |

更新时机写反是最常见的 bug：最短型如果放在循环外，拿到的是被收缩坏了的窗口。

## 四、模板

### 变长窗口（求最长）

```js
let left = 0
let ans = 0
for (let right = 0; right < s.length; right++) {
  // ① 纳入 s[right]，维护窗口统计量
  // ② 窗口不合法 → while 收缩（不是 if）
  while (不合法) {
    // 移出 s[left]，恢复统计量
    left++
  }
  // ③ 此刻窗口合法，更新答案
  ans = Math.max(ans, right - left + 1)
}
```

### 定长窗口

```js
for (let right = 0; right < nums.length; right++) {
  // 加入 nums[right]
  if (right >= k - 1) {
    // 窗口长度恰为 k：统计答案
    // 再移出 nums[right - k + 1]
  }
}
```

## 五、复杂度

`for + while` 看着是两层循环，但 `left`、`right` **各自只单向移动、最多走 n 步**，总移动次数 ≤ 2n → 均摊 **O(n)**。空间取决于统计量：哈希表 O(字符集)、计数数组 O(1)、单调队列 O(k)。

## 六、常见坑

1. 收缩必须用 `while`：一次扩张可能让窗口连续非法多步。
2. 「记录位置 + 跳转式收缩」时，要判断记录的位置**是否落在当前窗口内**（见 003 的 `last.get(c) >= left`），否则会把 `left` 往回拖，破坏不变量。
3. 窗口内统计量（计数、和）在收缩时要**成对还原**，别只加不减。
4. `left` 永不回退是这个技巧的**不变量**；一旦破坏，复杂度就退回暴力枚举 O(n²)。

## 七、相关变体

- **单调队列**：窗口要的不是「计数」而是「最值」时，用双端队列维护递减序列，队首即窗口最大值 → [239](./239-sliding-window-maximum.md)。
- **固定长度 + 字符计数**：567 字符串的排列（异位词窗口）。
- **变长 + 哈希计数**：76 最小覆盖子串（最短型窗口的代表）。
